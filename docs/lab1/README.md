# Проверка лабораторной работы 1

## Проверка HTML

Все три страницы проекта BookNest были проверены с помощью W3C Markup Validator.

Результат проверки: ошибок HTML не обнаружено.

Проверенные страницы:
- index.html
- book.html
- loan.html

## Проверка доступности

Для проверки доступности использован Lighthouse.

Результат проверки страницы: Accessibility — 95.

Основные требования доступности:
- навигация по странице с клавиатуры;
- все поля формы имеют связанные элементы label;
- изображения имеют альтернативный текст;
- используется семантическая HTML5-разметка;
- структура заголовков соблюдена.

## Проверка клавиатурной навигации

Навигация по страницам была выполнена с помощью клавиши Tab.

Все интерактивные элементы доступны с клавиатуры. Переход между элементами выполняется последовательно. Для обратного перехода использовалась комбинация Shift + Tab.

## Структура проекта

Проект содержит три основные страницы:

- index.html — каталог книг;
- book.html — карточка книги;
- loan.html — форма выдачи книги.

Также используется папка assets/images для изображений.
