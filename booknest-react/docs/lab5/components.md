# BookNest — схема компонентов (ЛР 5)

## Дерево компонентов

- `App` — владелец состояния поиска, фильтров, сортировки, страницы, списка желаемого и состояния загрузки.
  - `Header` — заголовок приложения.
  - `FiltersPanel` — поле поиска, жанр, сортировка и фильтр доступности.
    - `Button` — кнопки управления.
  - `BookList` — список найденных книг.
    - `BookCard` — карточка книги.
      - `Badge` — метки жанра и другой информации.
      - `Button` — действия с книгой.
  - `Pagination` — переключение страниц.
    - `Button` — переход назад и вперёд.
  - `Wishlist` — список желаемого.
    - `BookCard` — повторное использование карточки книги.
  - `Spinner` — индикатор загрузки.
  - `EmptyState` — сообщение об отсутствии результатов.
  - `ErrorBox` — сообщение об ошибке и повторный запрос.

## Владение состоянием

- `App`: поисковый запрос, выбранный жанр, сортировка, фильтр доступности, текущая страница, книги, общее количество, состояние загрузки и список желаемого.
- `BookCard`, `Badge`, `Button`, `Spinner`, `EmptyState`, `ErrorBox`, `Header`, `BookList`, `Pagination`, `FiltersPanel` и `Wishlist` получают данные через props.
- Список желаемого сохраняется в `localStorage`.
- Данные каталога загружаются через API-модули; производные списки вычисляются при рендеринге.

## Принципы

- Компоненты интерфейса переиспользуются.
- Props типизируются через `interface`.
- Состояние обновляется иммутабельно.
- Индексы массива не используются как `key`.
- Компоненты не обращаются напрямую к DOM через `document`.
